Welcome to RoboTrack!
This is a mainly LEGO Spike-related project about tracking the robot.
LEGO Spike does not have a built-in GPS function (obviously). However, using sin(), cos() and tan(), I was able to build this project named RoboTrack. This is called odometry.
This system, originated from the First Lego League, consists of a custom-built pybricks-based firmware and a main.py script in python-robot/main.py.

Instructions on how to install.
Go to code.pybricks.com to view the official Pybricks coding website. Using the flashing tool you can install custom firmware.
I compiled it so you don't have to, it's hell to do so using packages. ;)
You can always view the source, but compiled version is in pybricks-custom-firmware-src/build
